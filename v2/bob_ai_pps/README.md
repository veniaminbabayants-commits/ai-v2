# TYLER-AI Справочник Amazing Online ©veny_b

Локальный Windows-оверлей + локальный API-сервер, который ищет по добавленным страницам форума и отвечает через Yandex Cloud AI Studio.

## Что уже умеет MVP
- Окно поверх других окон в Windows.
- Горячая клавиша `F10` — показать/скрыть окно.
- Чат с историей в пределах текущего запуска.
- Добавление URL страниц в базу знаний через интерфейс backend API.
- Извлечение текста страниц, разбиение на фрагменты и сохранение в SQLite.
- Поиск релевантных фрагментов по словам перед отправкой контекста модели.
- Ответы на русском с URL источников.
- Выбор сервера, организации и сферы вопроса в окне.
- Метаданные источников в SQLite: сервер, организация, сфера.
- Существующая база автоматически дополняется новыми полями при старте.
- Не внедряется в процесс игры и не читает память игры.

## Важно
- Установи .NET 8 SDK и Python 3.11+.
- Нужны Yandex Cloud API-ключ и ID каталога. Они задаются переменными окружения и не сохраняются в исходном коде.
- Каждый друг при локальном запуске устанавливает backend и настраивает собственный ключ/каталог или другой разрешённый ему доступ к API.
- Убедись, что правила Amazing Online разрешают использование оверлея и облачного помощника.
- Первая версия не подключена к игровому серверу: она отвечает только по тем страницам, которые ты добавил.
- Страницы, требующие авторизации или динамического JavaScript, могут не импортироваться. Добавляй только материалы, к которым у тебя есть разрешённый доступ.

## 1. Запусти backend
Открой PowerShell в папке `backend`:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
$env:YANDEX_API_KEY="вставь_свой_API_ключ"
$env:YANDEX_FOLDER_ID="вставь_ID_каталога"
$env:YANDEX_MODEL="yandexgpt/latest"
uvicorn app:app --host 127.0.0.1 --port 8765
```

Оставь это окно открытым. Проверка: открой `http://127.0.0.1:8765/health`.

## 2. Добавь страницы форума
Открой в браузере `http://127.0.0.1:8765/docs`, найди `POST /sources/add` и отправь JSON:

```json
{
  "url": "https://example.com/rules-page",
  "title": "Правила сервера"
}
```

Используй реальные URL правил Amazing Online, к которым у тебя есть доступ. Посмотреть добавленные источники можно через `GET /sources`.

## 3. Запусти оверлей Windows
Открой второе окно PowerShell в папке `windows-overlay\BobAiOverlay`:

```powershell
dotnet run
```

Нажми `F10`, чтобы показать/скрыть окно. Введи вопрос в поле внизу и нажми Enter или кнопку «Отправить».

## Примечания по оверлею
- Для MVP окно находится поверх обычных окон. В некоторых полноэкранных режимах игры Windows может не показывать обычные topmost-окна поверх игры. Если так, попробуй безрамочный оконный режим игры.
- `F10` — глобальная горячая клавиша Windows; если она конфликтует с игрой, поменяй значение в `MainWindow.xaml.cs`.
- Не запускай приложение от имени администратора без необходимости.

## Фильтры и добавление источников

В оверлее выбери сервер, организацию и сферу. Backend ищет только среди источников, соответствующих фильтрам (источники с сервером `Все` и организацией `Общее` считаются общими).

Открой `http://127.0.0.1:8765/docs` → `POST /sources/add` → `Try it out`. Пример тела запроса:

```json
{
  "url": "https://forum.amazing-online.com/",
  "title": "Amazing Online — правила проекта",
  "server": "Все",
  "organization": "Общее",
  "sphere": "Правила проекта"
}
```

Допустимые сферы: `Правила проекта`, `Организации и уставы`, `Администрация и контакты`. Для каждой страницы указывай наиболее точные сервер, организацию и сферу. Если форум требует авторизацию или JavaScript, импорт URL может не сработать; не добавляй закрытые материалы без разрешения.

## Ограничения текущей версии

- Серверы и организации в списке оверлея пока заданы как стартовый набор; при необходимости отредактируй список в `MainWindow.xaml.cs`.
- Контент форума не предзагружен: нужно вручную импортировать страницы, доступные для чтения.
- Цитирование URL зависит от ответа модели; проверяй ссылки. В API ответ также возвращается `sources_used` с фрагментами и URL.
- Каждый запуск на другом ПК локальный: `127.0.0.1` не делает backend общедоступным.
